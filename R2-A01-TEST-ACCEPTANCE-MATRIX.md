## 1. PURPOSE & PRINCIPLES

This document defines the exact, executable acceptance criteria for every test scenario covering the five remediation areas (P1 through P5), the Failure Injection Matrix, and the 12 cross-cutting scientific regression gates.

### Core Testing Invariants:
1. **Zero Silent Degradation:** An architectural repair must never silently compromise existing valid neural dynamics, normative contracts, or empirical regression gates.
2. **Deterministic Rejection:** Any forbidden or conflicting operation must fail fast with an explicit `StatusCode` and leave machine state byte-for-byte identical to its pre-operation state.
3. **No Fixture Leaks:** Tests must operate on authentic machine instances and authentic mathematical representations.
4. **Explicit Case Accounting:** Exactly 30 distinct, numbered acceptance test scenarios (P1: 4, P2: 9, P3: 6, P4: 5, P5: 6) are defined below.

## 4. CROSS-CUTTING SCIENTIFIC REGRESSION GATES

Every candidate implementation of R2-A01 must successfully pass the following 12 gates without threshold relaxation or test modification:

1. **GATE-REG-01 (76-Test Production Baseline):** All 76 existing unit and integration tests in `tests/` must pass with 0 failures using portable glob-free execution (`python -m pytest tests/ -q`).
2. **GATE-REG-02 (Cold-Start Dual Owners):** Roots 34 and 56 must graduate distinct complete owners $z=8321$ (Branch $AB$ / Cat) and $z=8320$ (Branch $DB$ / Eagle) with active stable bindings.
3. **GATE-REG-03 (Next-Word Generation):** Prompt `['القط', 'يشرب']` must emit `"حليب"`; Prompt `['النسر', 'يشرب']` must emit `"ماء"`.
4. **GATE-REG-04 (Canonical EOS Learning):** Training with canonical EOS (`boundary=False`, `Marker.EOS`) must form native Assemblies with `Marker.EOS`.
5. **GATE-REG-05 (Cat Branch Autonomous Rollout):** Prompt `['القط']` must autonomously emit `('يشرب', 'حليب')` and cleanly halt with `StatusCode.GEN_STOP_EOS` via Assembly 2.
6. **GATE-REG-06 (Preservation of Eagle Collision):** Prompt `['النسر']` must emit `('يشرب', 'ماء')` and halt with `StatusCode.GEN_STOP_AMBIGUOUS` (preserving evidence of R1-M01 duplicate Assemblies 5 & 6 until R2-B).
7. **GATE-REG-07 (Exact Retrieval Immutability):** Hash of $W$ before and after 100 read-only episodes must be identical down to the byte; latent table materialized keys must be 100% unchanged.
8. **GATE-REG-08 (Provenance Rejection Zero-Bleed):** Rejecting a corrupted envelope must leave all open journal structures and machine state completely untouched.
9. **GATE-REG-09 (Outbox Atomicity Under Fault):** Outbox failure injection before commit must result in 0 attestations in the peripheral ledger.
10. **GATE-REG-10 (Latent Topology Abort Invariant):** 100% of latent slots and reverse index entries created during an aborted root must be restored.
11. **GATE-REG-11 (Deterministic Replay):** Exact duplicate event retries must return cached results in identical order.
12. **GATE-REG-12 (No Production Threshold Drift):** All constants ($\theta_{\text{read}}=0.08$, $M_{\text{read}}=0.04$, $\theta_{\text{OB}}=0.40$, $K_R=12$, $\rho_{\text{core}}=0.70$) remain byte-for-byte unchanged.
